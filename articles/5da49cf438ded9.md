Claude Code と Codex のセッションをブラウザの1画面で管理するツール「[agent-calendar](https://github.com/uiuifree/agent-calendar)」を公開しました。

リポジトリを選んでセッションを始め、指示・許可・変更の確認・片付けまでを、開発しながら同じ画面で進められます。

動いているセッションは日・週・月のカレンダーに並ぶので、どこで何が動いているかも一目で分かります。

![週の表示。1つ1つの帯がエージェントのセッションで、色はリポジトリごと](/images/agent-calendar/calendar-ja.png)

## 作ったもの

agent-calendar は、自分のマシンの中だけで動く Web アプリです。
Rust の1つのバイナリに画面を埋め込んでいて、画面は `127.0.0.1` でだけ開きます。

開発の流れに沿って、次のことができます。

### リポジトリからセッションを始める

GitHub の組織を選ぶと、その組織のリポジトリと手元の clone が並びます。

![組織のリポジトリと手元の clone。「ここで始める」でセッションを始める](/images/agent-calendar/repos-ja.png)

「ここで始める」を押すと、そのリポジトリで Claude Code か Codex の新しいセッションを始められます。
モデルと許可の範囲（読むだけ／ファイルの編集まで／自動判定）も、ここで選びます。

並行して進めたいときは、新しいブランチで git worktree を切って、そこで始められます。
ブランチは GitHub の既定のブランチから切るので、手元の作業コピーには触りません。

手元に clone が無いリポジトリは、同じ画面から clone できます。

### 会話を見ながら指示を出し、許可に答える

セッションの「会話」タブでは、それまでのやり取りをチャットの形で読めます。
自分の依頼は右、エージェントの返答は左に並び、実行したコマンドとその結果も1行ずつ残ります。

![会話タブ。依頼・返答・コマンドの実行結果が並び、下の入力欄から続きの指示を出せる](/images/agent-calendar/conversation-ja.png)

続きの指示は、下の入力欄から出せます。
許可の範囲（読むだけ／ファイルの編集まで／自動判定）を選んで送ると、裏でエージェントが動き、返答が会話に流れてきます。
スクリーンショットを貼り付けて渡すこともできます。

送った指示は元のセッションの記録に追記されます。
画面で続けた作業を、あとから端末で再開することもできます。

Claude が許可の要るコマンドを使うときは、画面に確認が出ます。
「許可」「拒否」のほかに「このリポジトリでは今後も許可」を選ぶと、次からは聞かれません。

端末のタブをいくつも行き来せずに、許可待ちのセッションへ答えられます。

### 変更を確かめる

セッションの「変更」タブで、まだ commit していない変更や、セッション中のコミットを GitHub 風の差分で見られます。

![セッションの変更を GitHub 風の差分で見る](/images/agent-calendar/changes-ja.png)

push 済みのブランチなら、GitHub の比較の画面や PR を作る画面へのリンクも出ます。

### 予定を組んで任せる

決めた時刻に、決めたリポジトリでエージェントに指示を実行させられます。
1回だけ・曜日の指定・時間帯の中で N 分ごと、から選びます。

予定ごとに専用の worktree で動かすこともできます。
結果はセッションとしてカレンダーに並びます。

### 作業場所を片付ける

リポジトリごとのメニューから、終わった worktree と手元のブランチを削除できます。
エージェントが実行中の worktree や、変更が残っているものは消しません。

### あとから振り返る

止まったセッションには、やったこと・状態（完了／途中／相談のみ）・残っていることの要約が付きます。
案件ごとの作業時間と、API 単価で換算した費用も集計できます。
費用は本体・サブエージェント・advisor に分けて出るので、どこに使っているかも分かります。

![案件ごとの作業時間と、API 単価で換算した費用](/images/agent-calendar/stats-ja.png)

画像のリポジトリ名や文章は、ツールの「スクショ用の表示」で作り物に置き換えています。

## なぜ作ったか

worktree を切って複数のセッションを並行で動かすのが、普段の開発のやり方になりました。

そうなると、端末のタブが増え続けます。
どのセッションが許可を待っているのか、どの worktree が残っているのかが分からなくなりました。

CLI を何本も同時に面倒を見るのも、だんだん手間になってきました。
Claude Code と Codex を使い分けると、起動も再開もコマンドが違います。
リポジトリごとに `cd` して起動し、続きをやるときはセッション ID を探して `--resume` に渡す、の繰り返しです。

リポジトリを選んで始めるところから、片付けるところまでを1つの画面にまとめたくて作りました。

## 使い方

Linux（WSL2 を含む）と macOS では、インストーラーで入れられます。

```sh
curl -fsSL https://raw.githubusercontent.com/uiuifree/agent-calendar/main/install.sh | sh
```

`~/.local/bin` に `agent-calendar` が入ります。
systemd のある Linux なら、ユーザーサービスとして常駐させるのが手軽です。

```sh
agent-calendar service install
```

それ以外の環境では、`serve` で起動します。

```sh
agent-calendar serve
```

起動したら <http://127.0.0.1:23848/> を開きます。
リポジトリの画面は `gh` のログインを使うので、先に `gh auth login` を済ませておきます。

新しい版が出ると、画面のヘッダーに更新の案内が出ます。

## 仕組み

セッションは、Claude Code と Codex が手元に残している記録から読みます。

| エージェント | 読む場所 |
|---|---|
| Claude Code | `~/.claude/projects/*/*.jsonl` |
| Codex CLI | `~/.codex/sessions/**/rollout-*.jsonl` |

画面からの指示は、裏で `claude -p --resume` や `codex exec resume` を実行して送ります。

## おわりに

worktree で複数のセッションを並行して動かしている方は、ぜひ使ってみてください。
